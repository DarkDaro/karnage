# UI atlases

Готовые UI-ассеты. Пересобираются `py -3.14 -B tools/ui_import.py`.

| Файл | Размер | Источник | Примечание |
|---|---:|---|---|
| `panel.png` | 48×48 | Kenney Fantasy UI Borders | 9-slice рамка, slice 12 |
| `button.png` | 190×49 | Kenney UI RPG | 9-slice кнопка, slice 12 |

`src/assets/ui.js` — загрузчик с fallback.
