# KARNAGE

Файтинг на Canvas 2D: 13 бойцов, 10 арен, аркада, бой против CPU и режим на двоих. Графика рисуется процедурно, звук синтезируется через Web Audio, шрифты лежат локально.

**Живая страница с игрой:** https://darkdaro.github.io/karnage/ — версия запущена и проверена.

## Возможности

- 13 бойцов с разной скоростью, весом, уроном и двумя спецприёмами.
- 10 арен с параллаксом, погодой и декором.
- Аркада, VS CPU, 2P за одной клавиатурой.
- Суперы, фаталити, комбо-счётчик, блок, бег, рывок, броски и special cancel.
- Damage scaling в длинных комбо.
- CC0-эффекты: `hitLight`, `hitHeavy`, `dust`, `block`, `smoke`, `dustRun`, `fireImpact`, `iceImpact`, `shadowImpact`, `explosion`.
- Арена «Кладбище» на ассетах GothicVania; остальные — процедурные.
- UI: 9-slice панели из Kenney Fantasy UI.
- Мобильный режим: touch D-pad, P/K/блок, пауза, safe-area; landscape предпочтителен.
- Локальные шрифты, без CDN.
- Настройки в главном меню: звук, голос, громкость, CRT, кровь, тряска и reduce motion.
- Звук по умолчанию выключен; настройки или `?sound=1` включают его.

- Python 3.14 — для `tools/audit.py` и `tools/assets_import.py`.

## Запуск

### Онлайн

GitHub Pages: https://darkdaro.github.io/karnage/ — страница запущена.

Проверено: титул, меню, 13 бойцов, 10 арен, FX-атласы, без 404 и ошибок в консоли.

Страница отдаёт корневой `index.html`, который загружает `release/app.js` и `release/assets`. После изменений в `src/` или `assets/` нужно выполнить `npm run build`, закоммитить `release/` и запушить.

### Готовая сборка

Открыть `index.html` в корне проекта двойным кликом. Он загружает `release/app.js` и локальные ассеты; сервер не нужен.

Папку `release/` можно переносить отдельно: внутри свой `index.html`, `app.js` и `assets/`.

### Разработка

```bash
npm ci
npm run dev
```

Открыть `http://127.0.0.1:8613/dev.html`.

После изменений в `src/` или `assets/` пересобрать релиз:

```bash
npm run build
```

`release/` — генерируемая папка. Правки нужно вносить в `src/` и `assets/`, а не в `release/`.

### Тесты

```bash
npx playwright install chromium
npm test
```

`npm test` собирает release, запускает unit-тесты и Playwright-сценарии.

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Ходьба | `A` / `D` | `←` / `→` |
| Прыжок | `W` | `↑` |
| Присед | `S` | `↓` |
| Рука | `J` | `I` |
| Нога | `K` | `O` |
| Блок | `L` | `P` |
| Апперкот | `S` + `J` | `↓` + `I` |
| Подсечка | `S` + `K` | `↓` + `O` |
| Roundhouse | назад + `K` | назад + `O` |
| Бег | двойной тап направления | двойной тап направления |
| Рывок-уклонение | бег + `L` | бег + `P` |
| Спецприём | направления + `J`/`K` | направления + `I`/`O` |
| Супер | `S`, `S` + `J` при полной ярости | `↓`, `↓` + `I` при полной ярости |
| Бросок | `J` + `K` вблизи | `I` + `O` вблизи |
| Фаталити | комбинация в окне `FINISH HIM` | комбинация в окне `FINISH HIM` |

`M` — звук. Звук по умолчанию выключен; настройки в главном меню или `?sound=1` в URL включают его, выбор сохраняется. `Esc` — пауза в бою и возврат назад в меню.

В главном меню пункт «НАСТРОЙКИ» открывает звук, голос, громкость, CRT, кровь, тряску и reduce motion. Управление: `W`/`S` — выбор, `A`/`D` — изменение, `J` — переключить, `Esc` — назад.

Комбинации спецприёмов и фаталити показываются в паузе и на экране выбора. В комбинациях `←`/`→` означают «назад/вперёд относительно взгляда», а не физическую сторону экрана.

Бросок делается `J` + `K` вблизи; он не блокируется и не ловит присед или прыжок. После попадания обычной атакой можно отменить её в спецприём; по блоку и промаху отмена не работает.

## Режимы

- **Аркада** — 12 противников с ростом сложности. Отдельный финальный босс запланирован.
- **Бой против CPU** — выбор бойца, соперника, сложности и арены.
- **Бой на двоих** — за одной клавиатурой.

```text

```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер без кеша |
| `npm run build` | Собирает `release/` через esbuild |
| `npm run build -- --minify` | Собирает release с минифицированным `app.js` |
| `npm test` | Сборка + unit + e2e |
| `npm run test:unit` | Проверка данных роспера |
| `npm run test:e2e` | Браузерные сценарии через dev-server |
| `npm run check` | Синтаксис, ESLint и аудит |
| `npm run audit` | UTF-8, BOM, скобки, ростер, документация |
| `npm run audit:fix-bom` | Удаляет UTF-8 BOM из текстовых файлов |
| `npm run audit:write-roster` | Обновляет таблицу роспера в `DEVNOTES.md` |
| `npm run assets:build` | Пересобирает атласы эффектов из `assets/vendor` |
