# Лицензии

## Шрифты

В проект включены локальные копии шрифтов с Google Fonts:

- **Russo One** — лицензия SIL Open Font License 1.1, `assets/fonts/OFL-RussoOne.txt`.
- **Rubik Mono One** — лицензия SIL Open Font License 1.1, `assets/fonts/OFL-RubikMonoOne.txt`.

Шрифты распространяются по OFL; файлы лицензий лежат рядом с шрифтами.

## Код игры

Лицензия кода пока не выбрана. До её выбора проект распространяется как `UNLICENSED`.
