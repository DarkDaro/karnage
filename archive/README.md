# Архив

Снимки для отката. Файлы не удаляются; каждый снимок имеет дату, причину и
контрольные суммы.

## 2026-10-24-baseline

- `karnage.html` — исходный монолит до выделения проекта.
- `karnage-concept.md` — исходный концепт.
- `DEVNOTES.md` — исходная техническая документация.
- `karnage.rar` — исходный архив.
- `SHA256SUMS.txt` — контрольные суммы.

Причина: старт проекта `karnage-game`, разделение HTML/CSS/шрифтов и
подготовка к разбору монолита на модули.

## 2026-10-24-infrastructure

- `release/` — рабочая папка запуска после выделения проекта.
- `SHA256SUMS.txt` — контрольные суммы release.

Причина: зафиксировать рабочее состояние перед разбором монолита на
игровые модули.

## 2026-10-24-preproduction

- `release/` — рабочая папка запуска после блокеров препродакшена.
- `SHA256SUMS.txt` — контрольные суммы release.

Причина: зафиксировать finish/KO, относительный ввод, суперы, статусы,
раунды, звук и сохранения перед добавлением босса и контента.

## 2026-10-24-fx-pilot

- `release/` — рабочая папка запуска после подключения CC0-эффектов.
- `SHA256SUMS.txt` — контрольные суммы release.

Причина: зафиксировать первый пилот ассетов: hitLight, hitHeavy, dust.

## 2026-10-24-handoff

- `release/` — рабочая папка запуска после технического прохода.
- `SHA256SUMS.txt` — контрольные суммы release.

Причина: handoff-снимок перед новым чатом: FX-пилот, mute по умолчанию,
blockstun/wakeup, announce/wipe, drawFx, P2-выбор и пауза при blur.

## 2026-10-24-final-tails

- `release/` — рабочая папка запуска после закрытия технических хвостов.
- `SHA256SUMS.txt` — контрольные суммы release.

Причина: зафиксировать skip cutscene, FINISH HIM timer, low/high block,
blockstun, wakeup, P2 select and FX pilot.
