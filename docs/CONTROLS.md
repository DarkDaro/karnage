# Управление

## Игрок 1

| Действие | Клавиша |
|---|---|
| Ходьба | `A` / `D` |
| Прыжок | `W` |
| Присед | `S` |
| Рука | `J` |
| Нога | `K` |
| Блок | `L` |
| Апперкот | `S` + `J` |
| Подсечка | `S` + `K` |
| Roundhouse | назад + `K` |
| Бег | двойной тап направления |
| Рывок-уклонение | бег + `L` |
| Спец | направления + `J`/`K` |
| Супер | `S`, `S` + `J` при полной ярости |
| Захват-бросок | `J` + `K` вблизи; у каждого бойца своё добивание |
| Фаталити | комбинация в окне `FINISH HIM` |

## Главное меню

| Действие | Клавиша |
|---|---|
| Выбор пункта | `W` / `S` или `↑` / `↓` |
| Подтвердить | `J`, `Enter` или `Space` |
| Настройки | пункт «НАСТРОЙКИ» |
| Тренировка | пункт «ТРЕНИРОВКА» |

В настройках:

- `W` / `S` — выбор строки;
- `A` / `D` или `←` / `→` — изменить значение;
- `J` / `Enter` / `Space` — переключить;
- `Esc` — назад в меню.

## Тренировка

- В меню выбери «ТРЕНИРОВКА», затем своего бойца.
- Манекен не атакует; HP и ярость не кончаются, таймера и KO нет.
- `T` — переключить стойку/блок манекена.
- `R` — сброс позиции и ресурсов.
- Внизу показан последний ввод; `Esc` — пауза с полным списком приёмов, выход — через «В МЕНЮ».

## Мобильное управление

Появляется на touch-устройствах:

- слева D-pad;
- справа `P` — рука, `K` — нога, `БЛОК`;
- сверху справа — пауза/назад.

В меню D-pad работает как навигация, `P` — подтвердить, `БЛОК` — назад. В портрете показывается подсказка повернуть телефон; ландшафт предпочтителен.

## Общее

- `M` — звук. Включён по умолчанию; настройки меняют его, выбор сохраняется.
- `Esc` — пауза в бою, назад в меню.
- Бросок не блокируется, но не ловит присед и прыжок. После захвата жертва удерживается, затем получает именное добивание с эффектом стихии.
- Фаталити: 10 секунд на добивание и 4 секунды на ввод комбинации; прогресс виден в панели, стрелки показываются с учётом взгляда.
- Командные нормалы: `вперёд+P`, `вперёд+K`, `назад+P`. Направление считается относительно взгляда.
- Командный бросок: `D+P+K`; обычный бросок остаётся на `P+K`. У Базальта и Ржавого есть фирменный `вперёд+P+K` с коротким армором и большим уроном.
- Target-combo: `P,P,K` (у Гейста и Аямэ `P,K`). Финишёр даёт бонусный урон и именную вспышку.
- Special cancel: после попадания обычной атакой можно сразу ввести спецприём; по блоку и промаху отмена не работает.
- Комбинации спецприёмов, бросков и фаталити — в паузе и на экране выбора.
- В комбинациях `←`/`→` означают «назад/вперёд относительно взгляда», а не физическую сторону экрана; в подсказках паузы и FINISH HIM стрелки уже пересчитаны под текущий взгляд.
