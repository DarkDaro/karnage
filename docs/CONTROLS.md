# Управление

## Игрок 1

| Действие | Клавиша |
|---|---|
| Ходьба | `A` / `D` |
| Прыжок | `W` |
| Присед | `S` |
| Рука | `J` |
| Нога | `K` |
| Блок | `L` |
| Апперкот | `S` + `J` |
| Подсечка | `S` + `K` |
| Roundhouse | назад + `K` |
| Бег | двойной тап направления |
| Рывок-уклонение | бег + `L` |
| Спец | направления + `J`/`K` |
| Супер | `S`, `S` + `J` при полной ярости |
| Бросок | `J` + `K` вблизи |
| Фаталити | комбинация в окне `FINISH HIM` |

## Главное меню

| Действие | Клавиша |
|---|---|
| Выбор пункта | `W` / `S` или `↑` / `↓` |
| Подтвердить | `J`, `Enter` или `Space` |
| Настройки | пункт «НАСТРОЙКИ» |

В настройках:

- `W` / `S` — выбор строки;
- `A` / `D` или `←` / `→` — изменить значение;
- `J` / `Enter` / `Space` — переключить;
- `Esc` — назад в меню.

## Общее

- `M` — звук. По умолчанию выключен; настройки или `?sound=1` включают, выбор сохраняется.
- `Esc` — пауза в бою, назад в меню.
- Бросок не блокируется, но не ловит присед и прыжок.
- Special cancel: после попадания обычной атакой можно сразу ввести спецприём; по блоку и промаху отмена не работает.
- Комбинации спецприёмов и фаталити — в паузе и на экране выбора.
- В комбинациях `←`/`→` означают «назад/вперёд относительно взгляда», а не физическую сторону экрана.
