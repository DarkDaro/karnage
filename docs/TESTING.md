# Тестирование

## Команды

```text
npm test              сборка release + unit + e2e
npm run test:unit     только unit
npm run test:e2e      только e2e через dev-server
npm run check         node --check + ESLint + audit.py
npm run audit         UTF-8, BOM, скобки, ростер, документация
npm run audit:fix-bom удалить UTF-8 BOM из текстовых файлов
npm run assets:build  пересобрать FX-атласы из assets/vendor
```

Сейчас `npm test` — 87 сценариев: 13 unit и 74 Playwright.
Тесты FX проверяют загрузку атласов, sprite-эффекты удара и приземления.
Тесты боя проверяют low/high-блок, damage scaling, захваты с именным добиванием, special cancel, пропуск фаталити и ввод во время hitstop.
Тесты аркады проверяют сохранение и продолжение после reload, финального босса, его уникальные приёмы, дату рекорда, завершение забега, концовку выбранного бойца и дедупликацию зала славы.
Тесты настроек проверяют вход из меню, сохранение переключателей и загрузку после reload.
Тесты текста проверяют имена, комбинации, броски, арены и концовки на пустые строки и битые символы.
Тесты мувсетов вводят каждую команду спеца, спец-2, супера и фаталити реальными клавишами и проверяют запуск и видимый эффект. Отдельные проверки требуют уникальных имён, цветов и эффектов фаталити и запрещают зеркальные совпадения их команд.
Тесты нормалов проверяют полный профиль каждого бойца (startup, recovery, range, hitbox, knockback, launch, статус), командные `вперёд+P`, `вперёд+K`, `назад+P`, роли набора и наземный каст `DUP`/`RUK`.
Тесты этапа 3 проверяют общий `P+K`, командный `D+P+K`, фирменный `вперёд+P+K` Базальта и Ржавого, стабильные 2–3 хита target-combo и juggle после launch.
Тест баланса проверяет границы урона, дальности, старта, суммарных кадров, DPS, скорости и командных бросков; цифры — в `docs/BALANCE.md`.
Тест CPU прогоняет семь пар, покрывающих всех бойцов, и требует завершения боя без зависаний.
Тест тренировки проверяет вход из меню, пассивного манекена, бесконечные HP/ярость, отсутствие KO, блок по `T`, показ ввода и сброс по `R`.
Мобильные тесты проверяют touch-контролы, навигацию по меню и portrait-раскладку без выхода кнопок за экран.
`release/` тестируется отдельно с диска через `file://`.

## Детерминированный прогон

Игра открывается как `http://127.0.0.1:8613/dev.html?debug=1` после
`npm run dev`. В этом режиме доступен `window.KARNAGE`:

- `step()` / `render()` — ручной кадр;
- `newBattle(...)`, `startRound()`, `startFatal(...)`;
- `startLadder(id)`, `resumeSavedArcade()`, `loadArcRun()`, `TOP()` — аркада;
- `setSeed(number)` — подменить `Math.random`;
- `snapshot()` — состояние без ссылок на объекты.

Для тестов rAF отключается через `page.addInitScript`; звук можно отключить
через `localStorage.karnageSnd=0`. Кадры гоняются вручную, без `setInterval`.
Для проверки звука используются WAV/MP3 из `assets/audio` после первого клика.

## Что проверяем

- загрузка без console errors;
- все экраны: title, menu, select, vs, fight, pause, top, ending, gameover;
- все 13 бойцов: отрисовка, спец, спец2, супер, фаталити;
- finish lock, KO lock, статусы, `spec2go`, `netT`;
- low/high-блок, damage scaling, броски `P+K`, special cancel, пропуск фаталити;
- настройки: вход из меню, CRT/кровь/тряска/reduce motion, localStorage;
- двойной KO, лимит раундов, announce/wipe, render без мутаций;
- FX-атласы и sprite-эффекты;
- битый localStorage;
- сохранение аркады, продолжение, финальный босс, его приёмы, дата `TOP` и дедупликация;
- portrait-раскладка touch-кнопок и мобильный viewport (после этапа UI);
- parity: старый baseline и новая сборка дают одинаковое состояние на
  одинаковом seed и одинаковых вводах.

## Аудит

`tools/audit.py` проверяет:

- UTF-8 и отсутствие битых символов;
- баланс скобок;
- id/комбо/фаталити/арены;
- синхронизацию таблицы роспера в `DEVNOTES.md`;
- комментарии, которые могли съесть код;
- отсутствие служебных файлов и посторонних маркеров;
- существование ассетов.

`npm run audit:write-roster` обновляет таблицу между маркерами
`<!-- ROSTER:START -->` и `<!-- ROSTER:END -->`.
